Tablet: eigenes Hintergrundbild (Wallpaper) ablegen
====================================================

Diese Ressource liefert absichtlich KEIN eigenes Hintergrundbild mit, damit
jeder Server sein eigenes Branding/Motiv verwenden kann.

Um dem Tablet einen echten Wallpaper-Hintergrund zu geben (Home-Bildschirm
und Kategorie-Ansicht), lege eine eigene Bilddatei genau hier ab:

    html/img/wallpaper.jpg

Fertig - beim nächsten Öffnen des Tablets wird das Bild automatisch als
Hintergrund geladen. Ohne Datei bleibt der bisherige dunkle Verlaufs-
Hintergrund sichtbar (kein kaputtes Bild, keine Fehlermeldung).

Empfohlenes Format
------------------
Das Tablet-Gehäuse hat ein Seitenverhältnis von ca. 3:2 (Querformat).
Empfohlene Auflösung: 2048 x 1330 Pixel (oder ein anderes Bild mit
ähnlichem Seitenverhältnis - es wird zentriert zugeschnitten, falls es
nicht exakt passt). Unterstützte Formate: .jpg, .jpeg, .png, .webp.

Diese Datei selbst hat keine Funktion und kann gelöscht werden, sobald
wallpaper.jpg im Ordner liegt.
